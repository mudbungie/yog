Operator report 2026-08-21: recent conversations in the §11 list all show a
preview like `<file path="instructions/00/AGENTS.md">` — the head of the
assembled context, not anything the operator said.

## Verified root cause (2026-08-21)

`Agent::preview` is derived from the WRONG DOCUMENT. The derivation reads
`steps/<agent-id>/001/request.json` — what lernie sent the model — and takes
the first text block's first non-blank line:

- `src/git_tree/enumerate.rs:94` → `preview_from_disk` (:242-246) →
  `src/git_tree/detect.rs:16-20` `extract_request_preview`; `content_text`
  (:26-36) takes the FIRST text block; `payload_headline` (:44-51) strips only
  the legacy identity stamp.
- Since the §3.7 instruction freeze (bl-aa8b, DESIGN:1353) a root's assembled
  context BEGINS with a pinned-instruction frame block whose text opens with
  `<file path="instructions/NN/...">` — so every fresh root previews as that
  tag. Even without that block, the operator's message block still carries the
  deposit envelope (`---\nfrom: …\ndeposited_at: …\n---`), so the headline
  would be `---` — which is what non-root agents' previews degrade to today.
- DESIGN §3.3 promises the opposite: DESIGN:615 "the name is the title; the
  first payload line is the preview", :616-619 ladder rung two = "the first
  payload line (the goal with the stamp stripped)".

## The change (source swap — one fact, one home)

The payload has a first-class home that the same enumerate pass ALREADY
opens and discards: `agents/<id>/goal.md`
(`src/git_tree/enumerate.rs:233-240` `goal_stamps_from_disk` reads it for two
stamps and throws the text away).

1. `src/git_tree/enumerate.rs:233-246` — have the goal read return the text
   alongside the stamps; derive `preview` from it via `detect::payload_headline`
   + `truncate_preview`; drop `preview_from_disk` and the `001/request.json`
   read (keep `request_in` for the `call_start_unix` use at :107).
2. `src/git_tree/detect.rs` — retire `extract_request_preview` +
   `content_text`; keep `payload_headline` + `truncate_preview`; update the
   module doc (:1-12).
3. `docs/DESIGN.md:8618` §12 module-map row for detect.rs must be reworded
   (tests/design_module_map.rs enforces), plus a §3.3 note that the payload's
   home is `goal.md`, not the request record. Amend the doc in the same change.
4. No change needed in `nav/convs/row.rs` / `nav/convs.rs` / the wire seats —
   they are correct given a correct `Agent::preview` and inherit the fix.

If the goal file is absent (it should not be — it is written at start), the
preview simply drops, same as today's no-request arm.
