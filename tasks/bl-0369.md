Operator intent: one swarm of machines, any of which can be the face, the hands or the model access for a conversation. Today a seat reads and writes, a foot (thrall) executes tools, and inference always runs where the server is, because the server's agent loop spawns the provider binary beside the workspace. Wanted: a turn whose inference runs on a different registered machine, using that machine's provider configuration and credentials, with nothing credential-shaped crossing the wire. Question to settle first: is this a new leaf grade and wire surface, or the foot's existing three gestures (advertise, wait on invocations, complete) carrying a provider call, with streaming as the one thing that surface lacks. Deliverable is a section in docs/REMOTE.md, not this body.
