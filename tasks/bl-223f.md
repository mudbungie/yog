Operator ruling 2026-08-30: every component ships a container image — yog (the server), litany (the engine CLI), thrall (the foot), lernie (the seat) — for deployment sanity, NOT for internal container semantics: nothing inside uses the container filesystem as a feature, images are just the unit of install. Each repo owns its Containerfile and a make target; the build must be reproducible from the pinned toolchain (rust-toolchain.toml) and produce the same musl-friendly story rule 6 protects. Decide and record in each repo: base image (scratch/distroless for static musl where the crate allows), what state mounts in (XDG dirs are the runtime contract — the image carries no state), and where images publish (a registry question — propose, do not push anywhere without the coordinated publish moment). The yog image is the post-severance UI-free server (bl-7942) — do not containerize the windowed binary.
