Round 2, lane swdev. yog main 5cd95986 (`cargo build --release`, yog 0.0.48), litany pinned =0.0.10, brazen =0.0.14, fresh isolated world, engine on 127.0.0.1:7772, foot enrolled.

## The gesture

    lernie start <ws> "<goal>" <a git dir>

answers, verbatim:

    {"kind":"prepared","ok":true,"prepared":{...}}
    {"conversation":"HarvestCavern","kind":"started","ok":true}

and the conversation never runs. Four starts out of four. What the seat can see:

    lernie conversations <ws>
      Working directory: <dir>  stopped  2m  1 member  1 waiting

    lernie attention
      <ws>/Working directory: <dir>  stopped  3m  1 queued  stopped, mail

    lernie steps <ws> <agent>
      this loop has taken no step

Nothing anywhere says why. `ok:true`, a queued deposit, and a stopped loop.

## Where the reason actually is

The ops trail HAS a row and it carries neither the exit code nor the text:

    {"argv":["litany","prompt","--name","HarvestCavern","--cwd",...],
     "client":"yog-client","exit":"-2","stderr":"","stdout":"",...}

`exit -2` for a process that exited 1. The diagnosis is in a file no gesture
reads, `<world>/state/yog/detached/<unix-ts>-<workspace>.err`:

    litany prompt: role "worker" grants tool "clients", which its governing
    config commit does not describe — no descriptions/tools/clients.json
    (ARCH §3.3 descriptions-always); described tools: apply_patch, bash, cd,
    dispatch, load_skill, message, python, read_file, search_history

That fault is bl-7d33 and is not this ball. THIS ball is that a driver
refusal reaches no reader: `/ops` shows a wrong exit code and an empty
stderr, and the captured bytes go to a path the boundary does not serve.

## Why it matters

The lane recovered only by reading a file inside the engines data root. On a
remote engine — which is the whole shape REMOTE describes — the operator has
no such reach: `lernie start` says ok, the row says stopped, and there is no
next question to ask. Every seat-side gesture that could carry it (`ops`,
`agent`, `steps`, `attention`) already exists and answers nothing.

## Expected

The ops row carries the childs real exit status and the stderr it already
captured; a conversation whose birth refused reads its refusal from the seat.

## Severity

p2, not p1, only because bl-7d33 removes the commonest cause. The blindness
outlives it: any driver that dies at birth for any reason lands here.
