Today the real-substrate harness is hand-invoked positional scripts (scripts/drive/{stories,cleanroom,yogdrive}.sh): no make verb touches it, the verdict is printf PASS/FAIL lines plus a single exit code, nothing checks the host for Xvfb/xdotool/ffmpeg before failing 10s into a seat claim, and every docs/drive-logs/ report is typed from a blank page. That toolchain friction is why the ladder went undriven for 11 days while 177 commits landed.

Deliver:
1. A make drive family wrapping seat/seed/run-*/cleanroom over an isolated scratch world. Never the live world — make ux / make reload stay as-is (they are the operator's live-world verbs by design, bl-6260).
2. A per-beat machine-keyable verdict: one JSONL row per beat (beat id, verdict, evidence path) written beside gestures.jsonl; the human printf lines stay.
3. A preflight that names every missing host tool at once instead of dying mid-drive.
4. A log-skeleton emitter: sha, host tuple, load, the beat table pre-filled from the verdict JSONL — a run's report starts generated and is hand-finished, matching the house style.

Deliberately excluded: CI wiring (the drive needs a wire and a display; make ci stays as-is).

Acceptance: a fresh agent with no prior context produces a full-ladder verdict with one command per script family, and the QUALITY.md §3 audit can cite the same primitives.
