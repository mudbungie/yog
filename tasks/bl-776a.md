DESIGN §7.2/§7.3, found by the §11-rule sweep (bl-7dca).

`Cadence` (`src/app/cadence.rs`) reads three bases out of `cadence.yaml` and
derives every period from them — `wound_grace`, `late_pass`, the
stale-snapshot threshold, the I4 poll floor. §7.2 says outright that each
derived period *"follows the tuning"* so no reader has to know the arithmetic.

**No reply carries any of them.** Grep `src/boundary/` for `Cadence`: nothing.
The bases are reachable only as raw text through `Query::ReadConfig`
(`ConfigFile::Cadence`), so a seat that wants a derived period must re-implement
`Cadence`'s arithmetic against a YAML file it also has to parse — two
implementations of one derivation, which is the drift this document exists to
prevent.

It bites hardest on **`wound_grace`** (bl-90bf, bl-18e8). The tree already
rules the gate is the seat's (`src/fixture.rs`: *"`wound_grace` is the seat's,
not the server's. The window left with bl-7942 and `WoundGrace` has had no
consumer in this crate since; what yog serves is the wound itself"*), and
`src/wire.rs` states why the server must still be able to say the number:
*"the §7.3 wound grace is the sum of every leg a fact crosses before a seat can
see it, and the last of those legs is the ask. A server that did not name the
period could not state the grace, and would raise the alarm the grace exists to
prevent."* Both are right and together they are the defect: the server computes
the number, the seat needs the number, and nothing hands it over. So today
either every seat hard-codes a window (which a `cadence.yaml` edit silently
falsifies) or every seat flashes a red no-response banner on healthy sends —
the exact alarm bl-90bf closed.

`src/app/grace.rs` / `crate::app::WoundGrace` is 100%-covered code with no
consumer, in the same class as bl-7cc8's residue.

Candidate shapes, not a foregone answer: a `cadence` object on the
`Query::Workspaces` answer beside `derived_at_unix` and the growth note (the
read every seat already makes at `ASK_PERIOD`, and where the staleness line
already rides); or a `Query::Cadence` of its own; or the wound carrying its own
"believe me after" stamp so the seat needs no period at all — which is the only
shape that also removes the arithmetic from the seat.

Whichever lands, amend DESIGN §7.2 (the periods paragraph) and §7.3 (the
bl-90bf row) to name the carrier, and decide `WoundGrace`'s fate with it.
