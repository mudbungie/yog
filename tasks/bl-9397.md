## Symptom

`make drive` — the whole real-substrate ladder, QUALITY §3 step 3 — dies before
its first beat and produces **no verdicts at all**:

```
=== run-headless   world: <scratch>/run-headless/data   evidence: <scratch>/run-headless/out
wall: <scratch>/run-headless/data/yog/world/walls/home/brazen
scripts/drive/beats_headless.sh: line 89: seed_balls: command not found

logskel: no verdicts.jsonl under <scratch> — reporting a verdict-less run.
drive.sh: 1 of the driven verbs reported failing beats
```

`run-headless` is the ladder's **only** run verb (drive.sh says so: "One verb
since bl-7942"), so this is the ladder, entire. The exit is 1 and the log
skeleton says NO VERDICTS PRODUCED — bl-d0a0's red-run report working exactly
as designed, and reporting a harness that cannot start.

## Cause

bl-7942 (the server severance) deleted `scripts/drive/beats_s3s4s6.sh`, which
was where **two** helpers the surviving run still spends were defined, and left
every call site standing. The first is `seed_balls()`, at
`scripts/drive/beats_headless.sh:89`:

```
  seed_balls "$data" >/dev/null
  ready=$(in_world "$data" bl create "board ready" …)
```

`grep -rn seed_balls scripts/` finds one call and zero definitions.

The second is **`in_world`** — `in_world() { d=$1; shift; XDG_DATA_HOME="$d"
yog exec --cwd "$d/proj" "$@"; }`, the §8.4 hatch — spent by
`beats_headless.sh` (four calls) and by `beats_s13.sh:95`, and also gone. It is
the worse of the two: its first call is written `>/dev/null 2>&1`, so under
`set -e` the run dies **saying nothing at all** — no "command not found", no
beat, no verdict. Restoring only `seed_balls` moves the silent death two lines
down rather than fixing anything.

The windowed beat files went with the window; the helpers they carried were the
headless run's too, and nothing moved them.

## What it costs

`seed_balls` is what lays the **project** the run drives: `git init` at
`<data>/proj`, `bl prime` into the world, and one ready ball. Without it the
three `bl create` calls beneath it run against no store, the S13 board rungs
have no columns, and the run dies at `set -eu` before S14-T8 ever boots an
engine. Every beat below line 89 is unreached.

## Repro

## The fix

Both bodies are recoverable verbatim from the deleted file's history, and each
went to the tier its consumers make it belong to:

- `seed_balls` into `beats_headless.sh`, its **one** caller — minus the inner
  `seed` call, because `run_headless` already lays the world seed one line
  before it writes the cadence, and a fixture saying that a second time is one
  fact in two places.
- `in_world` into `harness.sh`, by that file's own seam rule ("every `run_*`
  verb in every sourced `beats_*.sh` calls … so their one home is here") —
  two beats files spend it.

Verified: `run-headless` now reaches its last beat and reports **ALL BEATS
PASS** — 44 rows in `verdicts.jsonl`, S14/S2/S13/S11/S19/S18/S10 all green.
