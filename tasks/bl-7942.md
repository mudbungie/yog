yog becomes the standalone engine: no UI, inert by default.

- The eframe/egui/GL stack leaves the crate entirely; bare yog runs what is today `yog serve`. The dependency cut restores the headless story — the deploy target runs a server with no display stack.
- Window mode rides one deprecated release (overlapping the seat-severance ball), then drops.
- Ship-inert default per bl-37fd: zero enrolled thralls means no execution surface; a fresh install's first conversation is chat-only until a thrall is enrolled, and that is the intended posture, not a gap. Enrolling the local thrall is an explicit operator act even on one box. Removing the default deletes config, not code.

Deliverable: DESIGN §0/§8 amendments plus the implementation in this repo. This is the last step of the migration order — everything before it ships green with the window still present.
