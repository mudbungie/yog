The top-level help promises: `Every command answers --help.` The shipped command matrix disagrees.

`serve`, `seat`, `wire-certs`, `env`, `exec`, `gesture`, `lernie`, `bl`, and `bz` all answer `--help` with exit 0. `yog tool-host --help` instead exits 2 and says it takes no arguments. `yog help tool-host` is the workaround.

This regresses bl-52ed, whose governing text is: `bl-0ec2 required help to be higher-order and world-free: every command must answer --help in place.` It also required: `Add per-namespace zero-side-effect tests.` The later-added `tool-host` was absent from that roster, so the invariant regressed without a failing matrix.

Expected: exit 0 with a short tool-host usage page, matching `serve` and the declared every-command discovery invariant. Extend the roster test from a fixed historical list to the authoritative current command definitions so a new command cannot fall outside it silently.
