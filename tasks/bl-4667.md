The top-level help promises: `Every command answers --help.` The shipped command matrix disagrees.

`serve`, `seat`, `wire-certs`, `env`, `exec`, `gesture`, `lernie`, `bl`, and `bz` all answer `--help` with exit 0. `yog tool-host --help` instead exits 2 and says it takes no arguments.

Expected: exit 0 with a short tool-host usage page, matching `serve` and the declared every-command discovery invariant.

Actual: the one long-running client mode has no help path. This breaks both human discovery and a programmatic probe that walks the top-level roster.

Add the top-level roster matrix to the argv-surface coverage so another command cannot fall outside the invariant silently.
