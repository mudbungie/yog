A detached lernie prompt that dies after launch (e.g. the brazen 0.0.2/0.0.3 version-skew refusal, 2026-07-22) leaves exit -2 + empty stderr in ops.jsonl — indistinguishable from a clean launch. The UI shows nothing; the operator sees a prompt that 'does nothing'. Route the detached child's stderr to a per-spawn file (world state), fold a non-empty tail back into the op row on the next sweep, and let the §6 attention machinery stir on it. Derived, not stored twice: the file is the source, the row projection reads it.
