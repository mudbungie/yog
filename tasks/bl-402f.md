The Login pane renders ten identical 'Login <provider>' buttons. Nothing tells the operator which providers already hold credentials — S5 point 4 says presence renders ('presence renders, contents never do'). If the subtle brightness difference on some rows IS the presence signal it is unreadable; make it explicit (e.g. 'signed in' text/badge per row, ash for absent). And keyless providers (auth = none: local, ollama) render a Login button that can do nothing meaningful — a keyless row should state 'no credential needed' instead of offering a verb. Acceptance: a row with a credential present is visibly distinct with words not luminance alone; keyless rows offer no Login.
