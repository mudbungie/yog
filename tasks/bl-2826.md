UX testing, 2026-07-27 (the operator). Reproduced from his own live ops log.

## The trace

    1785138671  lernie new .../workspaces/<workspace>            exit 0
    1785138691  lernie prompt .../<workspace>  "…ops"            exit -2, sink 0 bytes  ← worked
    1785138704  lernie new .../workspaces/<workspace>        exit 0
    1785138712  lernie prompt .../<workspace>    "…is this real?"  exit -2, sink 307 bytes ← WRONG WORKSPACE

He minted `<workspace>`, then typed into the bottom composer and hit
Enter — and it fired into `<workspace>`, the workspace he had focused before the
mint. `<workspace>` on disk is a husk: `repo.git` only, no `agents/`,
no `inbox/`, no `steps/`. It was never prompted.

## Why

`src/shell/keys.rs:129` `mint_workspace` runs `run_prepare` and nothing else:

    pub(super) fn mint_workspace(model: &mut AppModel, state: &mut ShellState, lernie: &Cli, bl: &Cli) {
        let inputs = model.new_workspace_inputs();
        super::start_pane::run_prepare(model, &mut state.start, lernie, bl, inputs);
    }

`run_prepare` sets `start.pending` — the start-pane's editable-goal composer,
which does target the new workspace correctly (`send_pending` uses
`p.workspace`). But it never calls `model.focus_workspace`. So after a mint:

- the tab bar still highlights the old workspace,
- the side panel still lists the old workspace's conversations,
- the **bottom** composer's bare rung (`AppModel::start_bare_inputs` →
  "the focused one", `src/app/balls/starts.rs:72`) still resolves to the old
  workspace.

Two composers are on screen at once, aimed at two different workspaces, and
nothing on screen says which is which. The operator picks the one that looks
like the place you type — the bottom bar — and silently prompts the workspace
they just walked away from.

## Fix direction

Focus the minted workspace as part of the mint. `run_prepare` already knows the
prepared workspace (`prepared.workspace`); focusing it there makes every
surface agree with a single fact instead of two views disagreeing. Then the tab
bar moves, the conversation list follows, and both composers name the same
target — no new signal, no new flag.

DESIGN needs the sentence too: §3.4 / §8.1 step 1 and §11's tab-bar paragraph
describe the mint as "the same mint + `lernie new`, deliberately" and say
nothing about focus. If focus is part of the verb, the doc is the authority
that must say so (AGENTS.md: "don't implement a deviation: fix the doc").

## Acceptance

A drive beat: with workspace A focused, press `w`, then type into the bottom
composer and press Enter — the ops line must name the NEW workspace, and the
tab bar must show it selected.
