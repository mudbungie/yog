Round 1, lane comparator. yog 0.0.38 (main tip), lernie 0.1.30, isolated roots.

Reproduction, in order:

1. Mint a host on a lane port: `WIRE_HOST=127.0.0.1 WIRE_PORT=<p> yog wire-certs`.
2. Boot `yog`; create a workspace and start a conversation in it (verified
   present: `yog gesture "/workspaces"` returns the row).
3. Give the seat a channel by copying the HOST`s own `client.pem`/`client.key`/
   `ca.pem`/`address` into `<seat data root>/lernie/wire/workspaces/<ws>/` —
   i.e. a valid, CA-signed client leaf that was never `/enroll`ed into the
   workspace.
4. `lernie workspaces`

Observed:

    comp
        {"kind":"workspaces","ok":true,"rows":[]}

`ok:true`, zero rows. mTLS completed, the gesture was accepted, the engine
answered — and the answer is indistinguishable from "this engine holds no
workspaces at all". `lernie conversations comp` then says
`{"error":"unknown workspace \"comp\" — none is enumerated here","ok":false}`,
which reads as "the workspace does not exist" and points the operator at the
engine, not at their own registration.

After `yog gesture --ws comp "/enroll compseat2"` and installing THAT material,
the identical command returns the live rows. So the empty answer was the
registration fact and nothing else.

Expected: a client that is authenticated but registered in no workspace should
be told so — the same shape as the `/prompt` refusal, which is the best error in
the suite ("sign in first: no provider in this workspace`s wall holds a
credential … — /login <provider> (rows: …)"). Something like: this client
(<common name>) is registered in no workspace on this engine; enrol it with
`/enroll <name>` on the host and file the material under
`wire/workspaces/<workspace>/`.

Severity p3: nothing is lost and the remedy exists, but the failure is silent
and lands on a first-time user at the exact step where they cannot yet tell
their own mistake from a broken engine. REMOTE §5 makes registration the
durable participation fact; a read that returns the empty projection of that
fact without naming it makes the fact invisible.
