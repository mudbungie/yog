Found while instrumenting the sweeps (bl-49f4).

DESIGN §7.1's watch-root table lists seven `RootKind`s. `src/fs_watcher/roots.rs`
implements the allowlist for all seven:

    RootKind::BrazenConfig => rel == BRAZEN_CONFIG_FILE,
    RootKind::LernieConfig => rel == "models.yaml" || matches_any(&rel, &["workflows"]),

But `src/app/mod.rs::desired_watches` — the single site that decides what is
actually watched — arms only five:

    let mut desired = vec![
        (roots.names(), RootKind::NamesRoot),
        (roots.workspaces(), RootKind::WorkspacesRoot),
        (roots.replays(), RootKind::WorkspacesRoot),
        (roots.yog_state.clone(), RootKind::YogState),
        (roots.balls_clones.clone(), RootKind::BallsClones),
    ];
    desired.extend(workspaces.iter().map(|w| (w.path.clone(), RootKind::Workspace)));

`grep -rn "BrazenConfig\|LernieConfig" src` finds them ONLY in `roots.rs` and its
tests. No `Roots` field even holds the brazen config dir or the lernie config
root, so `desired_watches` could not name them today.

## Why this is a defect, and why the sweeps do NOT cover it

This is *not* drift in bl-49f4's sense: the 15 s full sweep does not re-read
config either (it reconciles, re-fetches balls, re-reads the ops tail, and marks
workspaces). So an external edit to the brazen `config.toml` or lernie's
`models.yaml` / `workflows/` — by the user's own `bz`/`$EDITOR`, by a second yog
instance, or by an agent — reaches no yog surface at all until the pane is
re-opened. §9's optimistic hash guard then refuses an Apply against content the
buffer never saw, which is the correct-but-late failure the watch was supposed
to prevent.

## The fix, roughly

Either arm the two roots (add the resolved brazen config dir and the lernie
config root to `Roots`, extend `desired_watches`, and route their dirtiness to a
config re-read) — or, if the design's real position is that config is read
on-demand and needs no watch, delete the two `RootKind` variants and the §7.1
rows, per AGENTS.md subtraction. Two representations of one fact drift; right
now the doc and the code disagree about which roots yog watches.
