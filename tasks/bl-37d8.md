First dispatched run of ingest.yml (bl-38dc) stepped the pins correctly, pushed its branch, then failed at the ci.yml dispatch: 403, resource not accessible by personal access token. advisories.yml carries the same line and would fail at the same step on its first real mend. The job already holds actions: write, and a workflow_dispatch is the one event the job token may raise; the release token is only needed for the push to main (so the push triggers CI and the release chain), and checkout already seats it in git's credentials. Fix: GH_TOKEN is the job token in both workflows.
