Engine side of REMOTE $13.2/$13.3: a 'relay' file at the flat wire root is the moor's target (absent = no moor, no thread, today byte for byte). The moor thread dials out, states {"moor": leaf}, pings at 25s idle, redials with bounded backoff on a dead write, and answers {"dial": token} by dialing a fresh back-leg that feeds the same connection-serving code the listener's accept feeds — which requires the serving loop to accept a generic Read+Write byte pipe rather than a TcpStream (TLS-in-TLS on spliced legs; a signature change, not a protocol one). First standing outbound connection the engine has ever held; its redial ladder is confined to the moor.
