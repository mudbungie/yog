Rework the icon landed by bl-7437 (DESIGN §11).

**the operator's verdict, verbatim:** "Probably over-indexed on the art-deco. Let's
make it look like tentacles. Also, the color palette of yog is like greens and
purples and blues and maybe some yellow-orange-red. This is way too pastel."

**Two changes:**
1. Shape — drop the stepped annulus-sector ziggurat. Each limb is a walked
   polyline: constant curl per step, geometrically shrinking step length (so
   curvature grows toward the tip), strong taper, suckers along the inner edge,
   and a glowing orb seated in the terminal coil.
2. Colour — the badge hues are tuned to read on a dark panel, which makes them
   pastel. Derive a saturated `deep()` variant from them rather than restating
   RGB triples, and swap SIGIL magenta for BRAZEN amber so the mark runs
   green / blue / amber about a gate-violet hub.

**Constraints that survive:** one geometry table, two faithful renderings
(`rgba()` + `svg()`); `assets/yog.svg` derived via `make icon`; transparency;
100% coverage; 300-line cap.
