Seen on a seat today: a parked shell call classified secret; the seat's ask offered pass at call, conversation and workspace scope; the operator picked a wider one and got 'a secret call takes --scope call only…' and the call stayed parked. The seat cannot know which scopes the judge permits without reading the reason's prose, which REMOTE forbids (the classification rides the wire so a seat never re-derives it). So the held object in the attention/queue reply gains scopes: the list of scope words an answer may take for this hold, computed by the same Scope::permits that judges the answer — call alone for secret and destructive, all three otherwise. Additive key, read by rung 3 on older seats; REMOTE's held row documented; no PROTOCOL bump.
