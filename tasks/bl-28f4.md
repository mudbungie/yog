Round 1, lane comparator.

Observation. Bringing an isolated engine up from nothing took this lane about an
hour, and most of it was assembling by hand an answer the engine already knows.
The facts exist, one gesture each: /providers knows every row's credential state
("auth oauth2 · signed in", "auth api_key · no credential stored"), /roles knows
what each role is pointed at, /clients knows who is registered and who is
present, /lineages and /governing know which config commit is in force, /ops
knows what the engine last did and whether it failed, and the wire material
either exists on disk or does not. What is missing is the verb that asks them
together and says, in one screen, whether this box can start a conversation.

The comparators all ship one, and each contributes a different idea.

codex — a scannable board with a tally and a hint row (codex doctor --summary):

    [ok] sandbox      restricted fs + restricted network · approval OnRequest
    ...
    17 ok | 1 idle | 2 notes | 0 warn | 0 fail ok

    Run codex doctor without --summary for detailed diagnostics.
    --all expand truncated lists       --json redacted report

Two ideas worth taking: the tally line, and the trailing two-column row that
teaches the flags you will want next. A third: codex's json flag is documented
as "Emit a redacted machine-readable report" — redaction is a first-class flag
on the diagnostic, which for a system with a leak gate is exactly the right
instinct.

hermes — the remedy on its own indented arrow line, and "not yet" distinguished
from "broken":

      x ~/.hermes/.env file missing
        -> Run 'hermes setup' to create one
      -> MEMORY.md not created yet (will be created when the agent first writes a memory)

Claude Code — its doctor is documented as "Reads settings files in the current
directory without a trust prompt", i.e. the diagnostic is explicitly exempt from
the gate that would otherwise stop it running. That matters here too: a doctor
must work on a box that is broken in the way it is diagnosing.

Proposed shape. A /doctor read gesture, folding the reads that already exist —
no new facts, no new state, no new file. One row per check, each carrying the
fact it read and, when it fails, the gesture that fixes it — which the engine
already does beautifully in one place, the /prompt refusal: "sign in first: no
provider in this workspace's wall holds a credential, so a conversation begun
here would reach no model — /login <provider> (rows: ...)". A doctor is that
sentence, once per check, asked before the failure instead of at it.

Checks the existing reads already support: wire material present and its
address; the listener bound; the world's roots resolved; per workspace — a
provider row with a credential, every role pointed at a row that has one, the
config lineage's tip and whether anything has diverged, the registered clients
and whether any is present; and the last non-clean row on the ops trail.

Two things to decide. Whether it is per-engine or per-workspace (probably both,
as /doctor and /doctor under --ws), and whether the reply is rows or a verdict —
rows, per the boundary's existing shape, with the tally as a header field so a
seat can paint codex's summary line without inventing it.

Filed p4: a comparator gap. Nothing is broken; the answer is just not asked
anywhere.

---

Round-1 install lane (STORIES S0/S9) reached this ball independently and reports it as the single cheapest large win in the suite — filed at p4, argued here for p2.

Walking a stranger from a bare ubuntu:24.04 container to a first reply, a doctor would have collapsed FIVE of the six things a first-time user trips on into one screen. The gates are met one at a time, each after a fresh failure, and each refusal is individually excellent and locally blind:

1. wire material minted but `address` reads 127.0.0.1:0 (bl-98ef)
2. seat wire directory unprovisioned, and the sentence teaches the visiting-box recipe (lernie bl-ad7f)
3. no git identity on the box, which kills the first start and wedges the workspace name (bl-c28c, bl-1af5)
4. the wall has no brazen config directory (bl-f627) and no role names a usable row (bl-8523, bl-21e9)
5. no foot enrolled, and the one available foot speaks PROTOCOL 8 against an engine speaking 13 (thrall bl-f88f)

Comparator evidence: hermes-agent 0.19.0 ships `hermes doctor`, which ends with a numbered "Found N issue(s) to address" list naming the command that fixes each, plus `hermes doctor --fix`. It is the one thing hermes does better than this suite by a clear margin, and it is not a hard verb — every fact it needs here is already derived somewhere in the tree.

Measured against it: once all eight acts are known, empty root to first reply is 4 seconds. The machinery is fast. What costs a stranger a day is finding out which of the five gates is currently shut.
