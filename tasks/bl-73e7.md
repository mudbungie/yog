Operator ruling 2026-08-22: streamed model output must reach the glass at
write cadence, not the 500ms ask cadence. The sanctioned shape is the one
REMOTE §10 pre-priced and §9.7 declined — a follow-class read on its own lane.
This ball is the operator reversing that decline; record the reversal in the
doc, do not soften it.

  ASK_PERIOD=500ms (`src/wire/asker.rs:50`, pass :86-101 — one TCP+mTLS

## The change

1. **A follow-class Query** (tail-shaped: the live stream of ONE agent,
   "keep it coming"): the server answers with frames as the stream grows and
   sends no terminator until the stream closes (step boundary / fd close).
   The frame shape is the settled one — the general path with more frames.
   No protocol change, no new dependency, sync std::net + rustls throughout,
   thread-per-held-connection (the mailbox hold is the precedent).
2. **A second asker lane**: a dedicated connection+thread for the follow
   read, so the serial 500ms pass is never stalled by a read that
   deliberately never finishes. Reconnect for this lane is simple re-ask on
   drop; while it is down the seat degrades to the pull path's 500ms chunks
   (graceful by construction — keep that fallback, do not delete the pull
   fold).
3. **Engine-side source**: feed the held answer from the incremental
   follower's mechanism (offset + partial-line + fold, follow.rs:139-157) or
   the fs-event it already keys on — NOT from whole-workspace rederivation.
   The follower finally gets its one real consumer; its client-side
   TailCell/overlay dead-end and 60Hz repaint pump retire. bl-6233's
   invariant holds: `inspector::live_tail`'s fold stays the ONE describer of
   the tail — the lane changes transport, never the fold, so two seats cannot
   describe one moment differently.
4. **Seat splice**: committed transcript stays on the pull `Query::Transcript`
   (memoize it again — restore the per-snapshot memo the migration deleted);
   the live tail arrives on the follow lane and splices at the existing
   `Transcript::with_live` seam (`src/transcript/mod.rs:183-197`, built for
   exactly this split).
5. **Cleanup folded in**: retarget/replace the phantom follower test to the
   real path; reconcile `src/app/live.rs` module docs.

## Tests

- Paint-layer beat: bytes appended to the open step file reach the glass
  with NO derivation pass and NO asker pass in between (the honest version
  of the phantom test).
- Lane isolation: a held follow read never delays the standing set's answers
  (drive both, assert the pull answers land on cadence).
- Fallback: drop/refuse the follow lane → the tail still arrives via the
  pull path at ask cadence; lane re-establishes and takes over.
- One-moment invariant: the follow-lane frame content equals the pull fold's
  content for the same bytes (bl-6233).
- Stream close: the terminator arrives at step boundary; the seat swaps to
  the committed entry without duplication (the with_live seam).
- Wire-level: server holds the connection across multiple growth events;
  zero-length frame semantics unchanged for every other query.
Paint assertions via crate::paint_probe only. FakeClock throughout; no
timing-sleep tests.
