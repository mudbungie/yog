**102 files (37% of the tree) sit at or above 200 lines; 52 sit within 50 lines of a hard gate.** That is the complaint: files ride the line, so any ball that touches one inherits a split obligation it did not sign up for, and the 300-line gate becomes a tripwire rather than a backstop. bl-2194 hit this live — its clean-rest test had to go into `src/app/tests/derive.rs` because `src/app/tests/focus.rs` was at 294/300 and splitting it was outside that ball's scope.

## The deliverable

Bring the tree to a **200-line aspirational target** by splitting along real seams. Explicitly:

- **200 is aspirational, not a new gate.** The hard cap stays 300. Do not add a second enforced threshold — a gate at 200 is just the cap moved, and AGENTS.md already argues that case against a 250 gate verbatim: *"A warning that fires on a fifth of the tree is noise, and a gate there is just the cap moved to 250."*
- **Mandatory core: every file ≥250 comes down** (52 files). That band is where the tripwire actually bites.
- **Opportunistic: the 200–249 band** (50 files) — take the ones with an honest seam; leave the ones where splitting would invent a boundary that isn't there.

## The binding constraint — segmentation, not line-shaving

AGENTS.md, verbatim: *"Over the cap? **Split along a real seam** and add the row to DESIGN §12; **never shave lines to duck the limit.**"*

A split that is not a real seam is worse than the long file: it adds a module boundary, an import, and a name, and buys nothing. The doctrine that governs the judgment, from the global AGENTS.md:

- *"Minimize interface. Make it deep and narrow enough that the consumer needs nothing behind it. Components meet only at the interface, never pairwise; the cost is coupling, not count."*
- *"Minimalism, subtraction in design. Build less. Code is context and context is inertia."*
- *"Single source of truth. Every fact has one authoritative home."*

So the sweep's first question on each file is **not** "where do I cut this in half" but **"why is this file this long?"** Three honest answers, three different actions:

1. **It does two things** → split at the seam; that is the target case.
2. **It does one thing thoroughly** (an exhaustive match, a big table, a codec) → possibly leave it, and say so. A 260-line total match arm-per-variant has no seam.
3. **It is long because of duplication or dead prose** → **delete, don't move.** Subtraction beats relocation. Report lines removed separately from lines relocated.

Test files count. Inline `mod tests` and `src/**/tests/*.rs` are under the same cap and the same reasoning — a test module that has grown to 290 lines usually mirrors a production file that grew two responsibilities.

## Definition of done

- No `.rs` file ≥250 lines, and a written justification for every file left in 200–249.
- Each new module has a **DESIGN §12 row** (path, budget, one-clause responsibility). See the sequencing warning below.
- `make check` green: fmt → lint (clippy + line-cap + rules-audit + cargo-deny) → **100% coverage**.
- **No behavior change.** This is a pure restructuring; if a split reveals a bug, file it separately rather than fixing it inline.
- Report: files split, seam chosen per file, lines *deleted* vs *relocated*, and the justified leave-alone list.

## SEQUENCING WARNING — collides with bl-43cd

**bl-43cd is the DESIGN.md rewrite (a fable is taking it).** Its investigation found §12's module table is the single hottest structure in the file — 37 of 68 all-time commits, 46 diff hunks inside the table — and recommended shrinking its rows.

This sweep **adds a §12 row per new module**, potentially 50–100 of them, to the exact table bl-43cd is rewriting. Markdown tables are one line per row, so the two collide by construction.

**These two must not run concurrently.** One of:
- land this sweep first, and let bl-43cd rewrite a §12 that already reflects the new module set (recommended — bl-43cd then rewrites the final shape once, rather than a shape about to change); or
- land bl-43cd first, and have this sweep append rows to whatever structure the rewrite leaves.

The operator sequences this. Do not start against a §12 another agent is mid-rewrite on.

## Not in scope

- Raising or lowering the 300-line hard cap.
- Adding a 200-line gate or warning (see above).
- Any behavior change, dependency change, or API redesign beyond what a seam split mechanically requires.
- `docs/*.md` — exempt from the cap and owned by bl-43cd.
