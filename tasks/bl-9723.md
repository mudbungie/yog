Operator report 2026-08-01. Two halves, one seam:

1. After launching yog, and after basic operations (starting/opening a conversation, switching workspace, sending a message, closing a modal — audit the set), keyboard focus should land in the message text box so the operator can just type. Today it does not.
2. Add a keyboard shortcut that moves focus to the message input from anywhere (pick an idiom consistent with existing yog keybinds; document it wherever keybinds are surfaced).

egui focus is per-frame (`Response::request_focus` / `Memory::request_focus`); the fix is likely a small 'request focus on next frame' state bit set by each operation, not scattered request_focus calls. Check DESIGN.md for any existing focus/keybind section and amend it.
