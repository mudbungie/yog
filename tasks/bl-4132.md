Found during the W14 clean-room run (docs/drive-logs/2026-07-26-w14-cleanroom.md): two concurrent drives (bl-97c7 and bl-c517) both used hardcoded Xvfb :99 and stole window focus from each other mid-typing — message payloads landed doubled/truncated. Beats passed only because they assert spawns/agents/replies, not payload text. Fix: yogdrive.sh allocates a free display per run (e.g. probe for an unused :N) instead of hardcoding :99; runners inherit it. Keeps parallel agent drives honest.
