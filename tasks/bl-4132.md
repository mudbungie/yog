DONE — the seat is per RUN, claimed by the runner, inherited through the environment.

## Design
- `yogdrive.sh seat` claims a display and prints `:N`. **Xvfb picks the free display itself** (`-displayfd 3`) rather than the harness probing for an unused :N: a probe-then-start races — two runners claiming in the same instant both see the same :N free and the loser's server never starts — and the server's own allocation cannot. The claim also waits until the display answers `xdotool getdisplaygeometry`, so `seat` never returns a display that is not yet up.
- `YOG_SEAT` is the whole interface: the runner exports it once and every later `yogdrive.sh` invocation — and every beats_* file stories.sh sources — inherits it. **No verb falls back to a default display**; without a seat every verb refuses loudly (`no seat — claim one first: export YOG_SEAT=$(yogdrive.sh seat)`), because a silent default is exactly the singleton this replaces. Nor does any verb start a server implicitly: that would drive an empty display and fail invisibly.
- `yogdrive.sh unseat` tears it down. A self-allocating Xvfb writes no `/tmp/.X<n>-lock` (skipping it is part of how it dodges the race), so `seat` records its pid at `/tmp/.yogdrive-X<n>.pid` — one file, addressed by YOG_SEAT alone, removed by unseat.
- Runners: `claim_seat` and `verdict` are new shared helpers in stories.sh. Every run function (`run`, `run_s3s4s6`, `run_s5s8`, `run_s7`) opens with `claim_seat` and closes with `verdict "$out"` — which drops the seat and then prints the verdict, so a run cannot report PASS and leak its X server. That also subtracted the three-line verdict tail duplicated across the four runners. cleanroom.sh needs no change (it execs stories.sh; Xvfb/mktemp/xdotool are all /usr/bin, inside the room).
- docs/STORIES.md's yogdrive.sh paragraph updated: the seat is per run, why, and the seat/unseat verbs.

## Proof — two concurrent drives, no wire spend
Two runners started at the same instant, each seeding its own world with its own ready ball, each claiming a seat, each pressing Escape+s (§11 ▶ Start) in its own window:

    A seat=:2 ball=bl-5b5a     B seat=:3 ball=bl-c077
    A: claim rows=1, trail holds bl-5b5a only
    B: claim rows=1, trail holds bl-c077 only
    seats differ: :2 / :3 ; after unseat, 0 Xvfb left and 0 pid files left

That is the focus-theft assertion in its sharpest form: under the old singleton one window took both keystrokes, so one world would show two claims (or zero). Each world got exactly its own, and the screenshots are per-seat.

## Proof — the runner integration, live wire
`scripts/drive/stories.sh run` on the per-run seat: prints `seat: :2`, **8/8 ALL BEATS PASS**, and leaves no Xvfb behind.
