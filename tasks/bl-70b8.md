Filed by Alkaloid 2026-08-11, synthesizing findings from bl-36c3, bl-f16e, bl-37bf, bl-45c7, bl-0e44, bl-bc06 and bl-8257. **Prompted by Fretwork's observation that this is one pattern being filed three times.**

## Why a synthesis ball and not three more instances

Every instance below was found by an agent who happened to be standing nearby, never by the suite. Two of them had **already been documented** — bl-63a1 recorded the vocabulary gap verbatim and it recurred; the vacuity heuristic was written on bl-f16e and a new shape appeared the same day. **Documenting the shapes has demonstrably not prevented them.** What closes a class here is a check, the way `make line-cap` closes the file-size class.

## The seven shapes, each with the instance that proved it

1. **Wrong source** — asserting on input text rather than painted glyphs. `paint_probe` read `Galley::text()`; **1815 tests passed while blind to every elision**. Fixed in bl-bc06 — but bl-36c3 then found **two surviving private copies** of the same walk, so fixing the shared home did not reach the duplicates.
2. **Wrong predicate** — a check satisfied by something other than the behaviour. An unset `$minted` made `grep -q '""'` match anything; an ack beat read a watermark written ~40 beats earlier by a different step.
3. **Wrong axis** — pinning *what* is painted when the defect is *where*. `inboxview/tests.rs` pins the empty-state string but not its position, and the defect is the anchoring.
4. **Deleted or truncated assertions** — **100% line coverage cannot see one.** Coverage measures lines *executed*, not *asserted*; a truncated body still executes the code. Caught once only by an unrelated `unused_import`.
5. **Assumed preconditions** — a test that CONSTRUCTS the ambient state the code depends on cannot discover the code requires it. Both of bl-bc06's new tests built a `Truncate`-rooted panel, so neither could see that rule 1b broke in the centre, where egui defaults to `Extend`.
6. **Unreachable surface** — no fixture reaches it at all. `shell/bootstrap.rs` was **never rendered by any test**, and the test named for it passed on a different pane's box (bl-37bf).
7. **The beat that never runs** — worst of all, because it leaves no trace. Beats files source into one flat bash namespace, so two stages sharing a name silently collapse; three beats stopped existing and **the ladder still printed `ALL BEATS PASS`**, since a beat that never runs writes no verdict row.

Plus the near-relative in **bl-45c7**: an invariant scan enumerating *field names*, silent when the same fact appears under a new one.

## What to land — checks, not prose

Several of these are already mechanical. Land them where the repo puts policy (`make lint` / `rules/*.yml` / the pre-commit gate), not in reviewer memory:

- **Shape 4:** test-name inventory diff. Landed by hand twice today (`0 removed, 4 added`, by sorted name diff). Make it a check, not a habit.
- **Shape 7:** duplicate top-level beat-function refusal. **Already landed** in `stories.sh` under bl-0e44 — mutation-tested both directions. Confirm it survives and generalize if other flat namespaces exist.
- **Shape 6:** surface reachability — assert every paint surface is rendered by at least one test. `acceptance::window`/`SIZES` already enumerate the window; the missing half is naming the surfaces.
- **Shape 1:** forbid hand-rolled paint walks outside `paint_probe`. An ast-grep rule, the same shape as `rules/no-bare-command.yml`.
- **Shape 2:** `grep -q` patterns carrying no id, and interpolated variables set by a command that can return nothing (heuristic already on bl-f16e).

## Constraints

- **Not defeatable by an inline exception** — rule 5's reasoning applies: suppressions live in one reviewable manifest.
- **Each check must be proved to bite** by planting the defect it forbids, in the shape the author would not have thought of.
- **Do not attempt all seven.** Take the mechanical ones; for any shape where a check costs more than it saves, record that decision with its reason rather than omitting it silently.

## Relationship to the open balls

bl-f16e (drive sweep) and bl-45c7 (scan vocabulary) are **instances** and stay independent — this ball is the mechanism that stops new instances. Do not close them into it.

## An eighth shape, and it is the mirror of shape 7 (Kestrel, bl-9006 — via Alkaloid)

**8. The conflated predicate — an assertion that is over-broad rather than unreached.**

`stories_inv1`'s *"idle logs no ops line"* used **"the ops tail is empty"** as a stand-in for **"no mutating verb ran"**. Those two agree on a fast machine and diverge exactly under load, because §7.2 mandates a `yog-drift late` line whenever a pass itself takes ≥ the cheap-sweep period (`CHEAP_SWEEP` is 2s; under nine concurrent tarpaulins a pass really does exceed it). The `late` line is not a verb's tell, and the beat had no way to say so.

Note this is the **mirror** of shape 7: not an assertion that never runs, but one that runs over more than it means. Both read green-or-red for reasons unrelated to the claim in their name. Sweeping for shape 7 will not find shape 8 — ask separately, of every assertion: *does its predicate mean exactly what its name claims, or is it a proxy that happens to correlate?*

**The resolution is worth recording too, because 'flaky test' and 'sweep bug' were both wrong.** DESIGN disagreed with itself: **I7** (*yog never mutates any substrate except on an explicit user action*) against **§7.2** (the watcher's own drift is written down whenever it occurs). Code matched §7.2, the beat matched I7. Fixed by amending the doc — I7 now names the exception, because a `yog-drift` line is an accusation about yog's *own fidelity*, not a change to the operator's world, and the alternative is the silent repair I7 forbids most.

## A systemic finding that belongs in this ball's scope

`tests/integration/support/clock.rs` had to be **created**: the `Arc&lt;dyn Clock&gt;` seam existed but the integration crate never used it, so **every beat in that crate had been measuring the machine**. That is a whole test tier with no control over time.

The strict-gain evidence: five real-clock passes all finished inside one cadence, so the old beat swept exactly **once** and every pass after the first swept nothing. It looked like five passes of coverage and was one.

**Candidate mechanical check for this ball:** an integration beat that depends on elapsed time must drive a clock rather than read one. `Instant::now()` (or a `SystemClock`) reaching a deriver under test is the tell, and it is greppable — the same shape as `rules/no-bare-command.yml`.

## Two checks landed and proved, five shapes decided against (Ingot)

The ball says: do not attempt all seven; take the mechanical ones; record every skip with its reason.

### LANDED — shape 1: rules/no-hand-rolled-paint-walk.yml, and it caught a LIVE third instance

An ast-grep rule refusing 'Galley::text()' outside src/paint_probe.rs, with a fixture in rules/fixtures/violations.rs so 'make rules-audit' proves it still bites.

**It was not clean on arrival.** A private copy of the walk was still live in 'src/shell/acceptance/screen.rs' — 'find()', matching 'egui::Shape::Text(t) if t.galley.text() == text' — and it is the walk that aims EVERY pointer test's click:

    tabs.rs:140  rect_of(&shapes, "new conversation")
    tabs.rs:143  rect_of(&shapes, "Login (bz browser sign-in)")
    tabs.rs:183  rect_of(&shapes, tab.label())

'Galley::text()' is the string that went IN, so a row egui truncated to 'Login (bz browser…' still reports the whole label: 'find' handed back its rect and the test clicked confidently at a seat whose PAINTED text was not what it named. bl-bc06 fixed the shared home (1815 tests passed while covering no truncation at all) and bl-36c3 swept for copies and found two; **this one was private to the acceptance harness and survived both sweeps.** That is the ball's thesis proven on itself: a fix does not reach the copy nobody knows about, and only a check does.

Repaired to go through 'paint_probe::collect' (painted glyphs). All 98 'shell::acceptance' tests still pass, so the repair broke nothing — and the beats would now redden if any aimed label were elided, which they could not do before.

**Proved to bite, in the shape the author would not have thought of:** restoring the real 'find()' body reddens 'ast-grep scan src' at screen.rs:205 by name; removing it goes quiet; the fixture is flagged in 'make rules-audit' both directions.

Not a ban on the galley. '.size()', '.rect', '.rows.len()' are untouched and correct — 'form_ui.rs:244' reads 'galley.size().x' and is not flagged. It is the TEXT that lies, so it is the text that is refused.

### LANDED — shapes 7-mirror and 2: scripts/beat-audit.sh, wired into make lint

Two shell-side checks over scripts/drive/, with a '--self-test' in the leak-scan discipline (the fixture must be flagged for BOTH shapes AND the real harness must not be), because a check dies by silently matching nothing and then passing everything forever.

**(a) A beat writes both a PASS and a FAIL, or it is not a beat.** 'gesture … || pass "…"' emits a row only when it succeeds, so the one outcome it exists to catch deletes the beat from the verdict instead of reddening it — bl-0e44's blindness reached by another road, and it was live: 'S8-T4 marks: balls landing branch is refused, not written' (fixed under bl-f16e). Measured over the whole harness it finds that one violation and ZERO false positives, so it needs no allowlist; a one-armed beat is never right. Currently 79 beats, all two-armed.

**(b) No 'grep -q' whose whole pattern is one interpolation.** An empty subject makes it 'grep -q ""', true of every stream, and it bites hardest when the beat ABOVE it is what failed to produce the id — twice now ('$minted' bl-afa7, '$refused' bl-f16e).

**'grep -qx' is exempt STRUCTURALLY, not by allowlist**, and this is the interesting part: '-x' anchors the pattern to a whole line, so an empty pattern matches only an EMPTY line and the vacuity is gone. preflight.sh:136's 'grep -qx -- "$p"' is the tree's one such site and it is correct. The first draft of the check flagged it; a check that cries wolf on the one shape that already answers the objection is shape 8 in the check itself, so the exemption is a property of '-x', not a name on a list.

**Proved to bite the real regression:** re-introducing the historical '|| pass' into beats_s8.sh makes 'make beat-audit' fail naming that exact label, and its self-test then also fails — correctly, since the harness is its clean fixture.

The third member of this family is structural and already in the harness: 'one_name_one_definition' (harness.sh, bl-0e44) refuses a duplicate top-level beat name outright. **Confirmed surviving** and extended under bl-f16e to cover the new 'wall.sh', mutation-tested both directions during that ball.

### Shape 7 generalization — asked and answered

'are there other flat namespaces?' — no. scripts/drive/ is the only place this repo sources multiple files into one shell namespace; every other script in scripts/ is executed, not sourced, and Rust has no such collision (a duplicate 'fn' is a compile error). Nothing to generalize to.

### SKIPPED, with reasons

- **Shape 4, the test-name inventory diff — NOT WORTH IT HERE, and it does not catch the recorded instance.** The instance was a TRUNCATED body ('caught once only by an unrelated unused_import'); an inventory diff catches DELETED tests, which is a different failure. And the cost is specific to this repo: a checked-in manifest that every new test must edit is an unconditional merge conflict between parallel builders — bl-0012 exists because ONE long line in DESIGN §12 does exactly that, and five builders were landing while I wrote this. A manifest touched by every test would be that defect institutionalized. The honest mechanism for a truncated assertion is mutation testing, which is a different ball and a much larger one.
- **Shape 5, assumed preconditions — not mechanically checkable.** 'this test CONSTRUCTS the ambient state the code depends on' is a statement about intent; no grep or AST pattern separates a fixture that sets up from a fixture that assumes away. The remedy is the design one already in the repo: assert against the DEFAULT, and let the test say which default it overrode.
- **Shape 6, surface reachability — real but out of proportion to this ball.** The check needs an enumeration of paint surfaces to compare against, and that enumeration does not exist; building it is the work, not the check. 'acceptance::window'/'SIZES' enumerate window SIZES, not surfaces. It deserves its own ball.
- **Shape 3, wrong axis — a design judgement, not a pattern.** 'you pinned WHAT and the defect is WHERE' cannot be told from a text assertion mechanically; every text assertion looks like a candidate. paint_probe already hands back '(text, rect)' from one walk, so the position is one field away — that is the affordance, and it is the most a check can do here.
- **The integration clock-seam lint — REFUSED because the obvious form is itself shape 8.** The tell suggested is 'Instant::now()/SystemClock reaching a deriver under test'. Measured: 13 integration files boot on 'SystemClock', and most are projections with no time dependence at all, where a real clock is harmless. Banning it conflates 'boots a model' with 'depends on elapsed time' — a predicate that runs over more than it means, which is precisely the eighth shape this ball added. It would need a 13-entry allowlist that nobody would burn down, and it would fire on 13 correct tests to catch a class of one. **The premise correction the ball needs:** 'tests/integration/support/clock.rs had to be created' is done — the file exists and carries the whole rationale — so the seam is now REACHABLE, which was the actual gap. What remains is a sweep of the beats that do depend on time, and that is a sweep, not a check.
