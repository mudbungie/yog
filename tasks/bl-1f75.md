Operator complaint, 2026-08-05: *"I'd like tool result collapses to show me the
number of characters in the output."*

## Where it lands

`src/transcript/rows/project.rs:78` — the `EntryKind::ToolResult` arm builds the
row as:

    let (glyph, _, phrase) = crate::theme::tool_result_badge(*is_error);
    out.push(row(key(&entry.name, 0), format!("{glyph} {phrase}"), content, …));

So a collapsed tool result says `✓ ok` (or the error wording) and nothing about
size. The operator cannot tell whether the `▶` opens onto four bytes or forty
thousand — which is exactly the decision the collapsed row exists to inform.

## The ask

The collapsed row states its payload's **character count**. `content.chars().count()`
— characters, as asked, not bytes: a byte count would lie about any transcript
carrying non-ASCII, and this row is read by a human sizing up a click.

## Design notes, to be attacked before implementing

- **The prefix seat is spoken for.** `project.rs`'s own comment: *"the prefix
  seat says them outright — it is this row's always-visible identity slot,
  worded for every other row class already."* Decide whether the count joins
  the prefix (`✓ ok · 12.4k chars`) or rides the row's weak/hover text, and say
  why in the comment. Whichever seat it takes, it must be visible **collapsed**
  — that is the entire point — and it must not shout: this is a size hint, not
  the row's identity.
- **One elision policy, not two.** `src/opslog/rows.rs:20` already owns *"the
  one elision policy"* for collapsed rows and there is a thousands rendering
  somewhere in the tree. Reuse the existing formatter rather than inventing a
  second way to write a big number; if none fits, add one home for it and use
  it from both.
- **Derived, never stored.** The count is `content`'s length at projection
  time. No field on `EntryKind::ToolResult`, no cache.
- The streaming tail (`EntryKind::Streaming`) is the sibling case — it grows.
  Decide explicitly whether it gets a live count or stays bare, and record the
  decision in the module doc rather than leaving it accidental.

## Work

1. The projection change plus its tests (`src/transcript/tests/`).
2. `docs/DESIGN.md` §11's transcript-row prose, if it enumerates what a
   collapsed row shows.
