bl-8ea9 reads "a restart is pending" as a kernel fact: the inode behind
`/proc/<pid>/exe` against the inode of the installed file. That is true of a
release the reconciler just installed, and it is equally true of ANY other
write to that path — including `scripts/install-main`, which this repository
ships and whose whole job is to make `~/.local/bin/yog` equal to `main`s tip
whenever `refs/heads/main` moves.

So on a box that has both, the sequence is: a ball closes, the ref moves,
install-main builds and installs an UNRELEASED main tip, and the reconciler's
next tick sees a different inode, reads the boundary, finds the engine idle and
restarts the operator's live engine onto code that has never been released.
install-main is explicit that it restarts nothing — "a running engine is a
service: whether and when to restart it is its unit's question" — and bl-8ea9
answered that question in a way that silently makes install-main a deploy.

Measured on this box: the close of bl-8ea9 itself triggered install-main, which
rebuilt and installed main's tip over the released 0.0.39 the reconciler had
put there twenty minutes earlier.

The rule the reconciler states is *the engine should be running the newest live
version*. The inode is not that rule; it is a proxy that was correct when the
reconciler was the only writer of the path. Read the rule directly instead:
compare the RUNNING engine's `--version` (through `/proc/<pid>/exe`) against
the INSTALLED binary's `--version`. After step 1 the installed binary IS the
newest live version, so the two comparisons agree exactly where they should and
differ only on the case that motivated this: a same-version binary swapped
underneath, which is a dev build and not a publication.

The decision table and its arms are unchanged — only the derivation of the
`pending` fact moves. The self-test's end-to-end cases already drive
`MainPID=0`, which stays `unknown`, so they need no edit.

A note in the README for the interaction, because a box that runs both is now
two writers of one path and the reader has to say which one it obeys.
