Operator report 2026-08-21: the outbox does not function properly while a
conversation is being instantiated by its first message. Exploration found the
start window (Enter → branch on disk) degrades every seat; eleven defects,
verified 2026-08-21. The unifying flaw: during the window the conversation has
no coherent address, and each seat improvises.

## The window

Enter with nothing selected → Action::Prepare (piped; lernie prime/new + bl
create/claim, seconds on a first start; acts are one FIFO so everything queues
behind it) → chained Prompt → engine mints the §3.3 name, detaches the driver,
returns the name → `await_conversation` sets the start echo (baseline 0) and
focuses the minted NAME (`src/app/focus.rs:90-93`, `src/app/echo.rs:73-81`).
Until the driver commits the branch, the name resolves nowhere: every
agent-addressed query and act refuses at
`src/boundary/address/agent.rs:153-171`.

## The change — dissolve the address hole, don't patch each seat

Design guidance (implementer owns the final shape; a special case is usually a
missing reframe — the pending conversation should be the GENERAL path with
empty inputs, not eleven branches):

1. A send aimed at the pending conversation must be HELD BY YOG and posted
   when the start resolves — never fired at an unresolvable name (dissolves
   D1, and D7's race: acts address resolved ids only). The echo mechanism
   already holds one send; the window's follow-up is the same held-send shape.
   DESIGN:2610-2622's "the next send replaces it: one send is in flight at a
   time" was written for two follow-ups, not for a follow-up replacing an
   unresolved START claim — amend it.
2. While a start is unresolved, Enter must not replace the Owes::Started hold
   or re-chain a Prompt with the unspent seed (D6). Prefer an existing
   explicit signal (state.acting) over a new flag.
3. Fold the start echo into the queue seat (D2 — delete the stale premise in
   seat.rs's doc) and migrate/preserve the draft across the name→id swap
   (D3/D4: clear exactly the text that was fired, not the seat).
4. Seats that KNOW the target is yog's own pending mint must not paint the
   boundary refusal (D5) nor offer Stop (D10) — the synthetic agent should
   carry an honest state, not Live.
5. D8/D9 fall out of the claim spending correctly (claim spent once; do not
   override intervening operator navigation — extend
   `the_claim_is_spent_once_and_leaves_later_focus_alone` to intervening
   focus).

This surface is shared with bl-78d8 (queue echo dedup) — this ball is
serialized behind it; merge main first and build on its reconciliation.
