The providers and catalog rows carry the qualified name alone. Both seats now group rows by machine and derive the machine by splitting on the last joiner, which disagrees with the server's own longest-registered-client match whenever a client or a row name contains the joiner. One optional field on the row, absent for the server's own rows, makes the grouping exact. Additive: an edition, not a protocol bump.
