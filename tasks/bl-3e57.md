The protocol number is a Rust declaration, so every gate that reads it hardcodes
a Rust path — and yog moved that path (bl-94a5 split `src/wire/hello.rs` into
`src/wire/hello/version.rs`) without any of them noticing.

## What is already broken

Each consumer's own `merge-release-pr` job fetches the published engine's
constant from a hardcoded `src/wire/hello.rs`. That file still exists but now
reads `pub use version::PROTOCOL;`, and the gates anchor on
`^\s*(pub..)?const PROTOCOL\s*:\s*u32\s*=\s*(\d+)\s*;` — a `pub use` matches
nothing. The fetch succeeds and the read finds no declaration, which every gate
treats as an unreadable input and HOLDS on. So the moment yog publishes 18 —
the event the consumers' holds are waiting for — none of them unblock, and each
prints a sentence blaming the engine for a stale path in its own file
(thrall bl-c618, verified against the real artefacts there).

yog's own roster (`scripts/protocol-gate.sh`) rots the same way in the other
direction: it names a Rust path per consumer, and any of the three splitting
its hello module makes yog's release gate hold forever on a number that is
right there.

## The ruling

The number gets ONE file-shaped home per repository that no split can move: a
top-level `PROTOCOL` file, one line, the integer. yog's `build.rs` turns it into
the compiled constant (`include!` of a generated const into
`src/wire/hello/version.rs`), so the file IS the source — there is no second
copy and nothing to hold equal to it. Each consumer does the same for its
vendored copy. `scripts/protocol-gate.sh` and every workflow read `PROTOCOL` at
the repo root of whatever tree, tag or main they judge. **No Rust path in any
roster.**

## In this repository

- `PROTOCOL` at the root; `build.rs` reads it, validates it and writes the
  const; `version.rs` keeps the changelog and includes the generated file.
- `scripts/protocol-gate.sh`: one path constant for all four reads, roster
  reduced to repository names, self-test rewritten over integer-file fixtures.
- `.github/workflows/release-automerge.yml` fetches `PROTOCOL` at the root.
- `Cargo.toml` include list and `tests/packaged_files.rs` gain the two new
  build inputs.
- REMOTE §3, AGENTS.md, the corpus refusal sentences and `corpus/README.md`
  point at the new home.

Filed by the fix lane that owns the four-repository landing; the three consumer
balls are thrall bl-c618 and its siblings in lernie and yog-android.
