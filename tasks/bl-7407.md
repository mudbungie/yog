REMOTE §9.7 class 2: the workspace tab bar. bl-44e9 attacked it and put it down, and what it found is the work.

The shape to build is the one §9.7 already rules for: focus held by NAME — the wire spelling — resolved at the doors that need a path (the pin toggle's ui.json key, the §3.6 delete seat). The shape to refuse is unchanged: painting off a reply while joining each name back against the engine's own in-process name/path table is two sources for one fact.

THE BLOCKER, which is the reason this is its own ball. A name resolves against the snapshot's enumerated workspaces, and the §3.4 raise focuses a workspace the enumeration does not carry yet: `lernie new` has returned, the derivation has not read the wall. Today the frame holds the path, so the composer's bare rung fires into the wall that was just raised. Name-keyed, that focus is unresolvable for as long as one derivation takes, and Enter inside that window fires into the PREVIOUS workspace — the defect the raise-adoption fix closed.

Migrating the tab bar to a reply does not dissolve it: the engine resolves the same name against the same snapshot and refuses for the same reason.

Two answers, and picking between them is the design half of this ball:

1. Re-derive the enumeration synchronously at the raise, so the wall is published before the focus names it. Cheap to state, and it puts a disk walk on the receipt path.

2. Hold the raised wall as a claim until the world catches up — the §3.4 start claim's own shape, one noun up. The claim already exists for the conversation; this is the same value for the workspace, retired by the same predicate (the derivation showing it). Adds no mechanism if it really is the same value.

Scope when unblocked: Focus.ws becomes the name; nav::tabs::Tab drops its PathBuf and `selected` compares names; the ~30 readers of the focused workspace resolve where they need a path. Pins stay keyed by path in ui.json — that is durable state and its own migration.

`Prepared::binding` waits on the same gate it always did (one seat's read path being the only read path) and is not this ball.
