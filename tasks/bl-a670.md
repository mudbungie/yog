Separately installed ends make version skew possible for the first time — until now one crate shipped both ends of every connection in lockstep, so the wire never needed a version. With four components installed independently, it does.

The handshake carries a protocol version. A mismatch is a fail-closed refusal that names both versions — no negotiation, no capability probing, no compat shims. The refusal is the upgrade prompt.

Authority restructure rides with it: REMOTE.md becomes the protocol authority all four components implement against; each repo's DESIGN governs only its own component. Where the wire is described in a component doc, the description cites REMOTE rather than restating it — one fact, one home.

Deliverable: REMOTE amendment (version field, refusal semantics, authority statement) plus the handshake change in this repo.
