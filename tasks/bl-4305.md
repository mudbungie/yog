src/transcript/render.rs (render_tool_result): a tool result row is
glyph + tool_use_id + verbatim content — whether the tool FAILED is carried by
✔ vs ✖ (and hydra-vs-ichor hue) alone. Delete the glyph and an error result is
indistinguishable from a success. Same seat in the steps drill-in
(src/steps_view/render.rs, render_tools): ✔/✖ + tool_id, no word.

Fix per the doctrine: say it — e.g. an "error" word (or hover) on the failed
case; keep ✔/✖ as the glance layer.
