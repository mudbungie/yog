Implementation of the bl-df65 design ruling, workspace side (DESIGN §3.1
as amended — "an operator-chosen sphere label"). The conversation side
(mint re-aim, preamble) is bl-2706/bl-1b5a/bl-2f30; this ball is the
workspace half. Read DESIGN §3.1, §3.4, §8.1, §11 first.

## The ruling being implemented

DESIGN §3.1 (as amended at bl-df65):

> **The name is chosen at creation, by the operator**: a short explicit
> label for the sphere — `ops`, `dev`, an employer — typed into the
> New-workspace affordance (§11). … yog validates what the wordlist used
> to guarantee by construction: lowercase ASCII alphanumeric words joined
> by single hyphens (`^[a-z0-9]+(-[a-z0-9]+)*$`), ≤ 32 bytes … and never
> the literal `unknown`. A name equal to an existing leaf under any of the
> three roots is refused outright — no suffixing, no prompt-loop.

> **The bootstrap names without asking.** The empty-world start (§3.4)
> creates its workspace under the fixed default name **`home`** — a
> constant, not a config, and not a mint.

§8.1 step 1: zero workspaces → `lernie new <root>/home`. §11: the slim
`new` tab opens a one-field name form, §3.1's validation inline, refusing
empty and collision. No rename verb exists (§3.1 migration paragraph):
replace + move balls + retention; existing minted leaves stay lawful.

## Changes

1. `src/names` grows the §3.1 validation (shape regex, ≤32 bytes,
   reserved `unknown`, leaf-collision refusal over the three-roots
   enumeration); the workspace mint call sites die — the wordlist mint
   survives only for conversations (bl-2706).
2. Bootstrap path (`start::plan` zero-workspace arm, §8.1 step 1): the
   constant `home` replaces the mint; New workspace verb takes the typed,
   validated name (shell one-field form on the `new` tab, `w` /
   Ctrl+Shift+N).
3. Validation failures render inline at the form (refused, with the
   reason), never as an ops wound — nothing spawned yet.
4. STORIES S0-T1 / S4-T1 already state the new argv
   (`lernie new <names-root>/home`; typed name validated) — make those
   tests true.

## Acceptance

- Empty world, bare submit → `lernie new <root>/home`, `YOG_NAME=home`.
- New workspace with `ops` → `lernie new <root>/ops`; with `Ops!`,
  `unknown`, an existing leaf, or empty → refused inline, no spawn.
- No code path mints a workspace name from the wordlist.
- `make check` green.
