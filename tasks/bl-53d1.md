## The four deliverables

1. **The key is `(provider row, model)` with a `"*"` row** (DESIGN §3.5, §4.1). `Prices` becomes provider → model → `Price`; `Prices::of(provider: Option<&str>, model: Option<&str>)` is ONE lookup: exact `(provider, model)`, else the row's `"*"`, else `None`; with `provider == None` the filter is empty — the model is matched over every row, `Some` when exactly one candidate prices it, `None` when more than one does. `{}` rates is a row priced at zero (`Price::default()`), which is `Some` and prices to `$0.00` — keep the present/absent distinction, add no status enum. A document in the old model-keyed shape reads as empty under the forgiving read (no migration; say so in the module doc). `StepBill` gains `provider: Option<String>` read off the step's `meta.json` `provider` key (litany bl-4c1c; absent today, so the fallback arm is the live one until the pin moves — test both).
2. **The door** (REMOTE §9.20). `Query::Prices` → `Reply::Prices { rows, ceiling, spent, released }`; `Action::Price { provider, model, rates: Option<Price> }`; `Action::Ceiling { usd: Option<f64> }`. Writes through `UiState`'s write-through (the `set_pinned` shape; add `set_prices`/`set_ceiling` in `ui_state/prices.rs`/`ceiling.rs`); both acts answer the re-derived `Prices` reply. Slash forms `/prices`, `/price <provider> <model> <input> <output> [<cache_read> [<cache_write>]]` (`off` deletes), `/ceiling <usd>|off`; help rows with the reasoning paragraph the gesture help carries. Refusals in band: negative or unparseable numbers; a provider row the world's wall roster does not know is NOT refused by the engine (a row may be priced before it is configured) — state that in the help.
   **The release.** `/ceiling` that moves the number back over `spend::of_world` (or deletes the key) enumerates every `refs/litany/held/*` mark in every workspace whose `reason` starts with `Ceiling::verdict`'s fixed head (`spend ceiling reached:`) and drives each through the same detached `litany advance` the `/answer` arm spends (`boundary::control`); the count rides back as `released`. Nothing else parked is touched. Until the sibling consult ball lands no such mark exists and `released` is `0` — implement it fully here regardless; the sibling only writes the marks.
3. **`cost` beside every token count on the wire** (REMOTE §9.20): `steps_view/wire.rs` rows gain `cost` (the step's own `StepBill` priced by its own `(provider, model)` — `StepSummary` gains the figure), `science/wire.rs` attempts gain `cost`, the rail notch encoder gains `cost` beside `budget`, `reply/ws_row.rs` gains `spend` (`spend::priced` over that workspace's `Snapshot::bills`). One encoder: the cost half of `board::figure_value`, factored so every carrier spells it identically; absent — never zero — when the table is empty. Decoders in `reply/decode`/`rows/decode` read them back; the strict round-trip tests cover present and absent.
4. **PROTOCOL 17, once.** `src/wire/hello.rs` bumps to 17 with its changelog line naming the four shapes and the three new spellings; `make corpus`; the corpus test green. Land items 2–4 in this one ball so the four shape changes cost one integer (REMOTE §3, §9.10).
