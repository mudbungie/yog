Makefile: both targets run `pkill -x yog`. That kills EVERY yog process on the machine: other operators' instances, UAT drives on isolated Xvfb seats, scratch-world instances. Observed live 2026-08-01: three UAT instances on an isolated seat died with SIGTERM (exit 143), zero stderr — the killer was a concurrent fleet's make ux loop in a bl worktree. Worse, scripts/bl-install-main calls make reload after every main merge, so every landed ball kills every running yog. Fix: kill only the instance these targets manage — e.g. record the launched pid in a runtime file keyed on the live XDG_DATA_HOME and kill that pid, or match the process by its world (its env/cwd), never by bare image name. Acceptance: two yog instances on different XDG_DATA_HOME; make ux restarts only the live-state one; the other survives.
