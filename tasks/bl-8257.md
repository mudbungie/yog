the rule the operator ruled into existence:

> the row is laid out prefix-first and the title's left edge is wherever the
> prefix ends, so every *conditional* element before the title moves the name
> column on the rows that have it.

bl-b9e3 moved the attention flag out of the prefix into the trailing
right-pinned group. **Three conditional prefix elements remain**, all in
`src/shell/conv_list.rs` `conversation_row`:

- the **live-activity chip** (`:141-144`) — painted only when `row.flight` is
  `Some`, one glyph in the class's hue.
- the **§10 uncertainty `?`** (`:145-148`) — painted only when `row.uncertain`.
- the **alignment verdict badge** (`:156-162`) — painted only when
  `row.verdict` is `Some`; absent entirely unless the workspace is armed.

Only the state badge (`:133-136`) is unconditional and therefore lawful in the
prefix.

**Why this was not folded into bl-b9e3.** That ball was scoped to the flag by
the operator ruling and by its own body ("Do **not** widen this ball to move
them; if the rule indicts them, say so in the doc and file a follow-up ball
naming them"). The doc says so; this is the ball.

**What this ball has to decide, not just do.** Moving all three right is the
obvious answer and it is not obviously right — the chip is deliberately beside
the state badge it agrees with (DESIGN §11: "the chip agrees with the state
badge beside it"), and the §10 `?` is spelled in DESIGN §11 as an
"uncertainty **suffix**" on the state badge, i.e. it is part of that badge's
reading, not an independent mark. Candidate answers:

1. move the verdict badge to the trailing group (it is a genuinely independent
   per-row mark) and leave the chip + `?` as a **fixed-width prefix cell** —
   always allocated, painted or blank — so presence stops moving the column
   while adjacency is kept.
2. move all three right, and amend §11's "suffix"/"beside it" wording.
3. rule the prefix's breathing acceptable for badge-adjacent marks and narrow
   the §11 rule to independent marks only.

Whichever wins, DESIGN §11 must end up saying it, and bl-6b83's geometry beat
(the title's left edge is unmoved by attention) should grow the sibling
assertions for whichever elements end up column-neutral.
